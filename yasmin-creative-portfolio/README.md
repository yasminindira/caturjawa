# Yasmin — Creative Portfolio

Portfolio personal responsive untuk GitHub Pages.

## Fitur
- Responsive HP, tablet, dan laptop
- Sticky navigation + mobile menu
- Smooth scrolling
- Scroll reveal animation
- Cursor glow desktop
- Animated marquee
- Project showcase cards
- Skills / toolbox section
- Journey timeline
- Contact CTA
- Custom favicon
- Tidak membutuhkan framework atau build tools

## Cara menjalankan
Buka `index.html` di browser.

## Deploy ke GitHub Pages
1. Upload seluruh isi folder ke repository GitHub.
2. Masuk ke **Settings → Pages**.
3. Pilih branch utama dan folder `/root`.
4. Simpan, lalu buka URL GitHub Pages yang diberikan.

## Catatan
Email pada tombol contact masih contoh: `hello@yasmin-portfolio.com`.
Link project `#` juga bisa diganti dengan URL project GitHub Pages milikmu.
